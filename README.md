# Prize Claw

A small browser extension game where you aim a claw and grab prizes.

## Install in Chrome or Edge

1. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
2. Turn on **Developer mode**.
3. Choose **Load unpacked**.
4. Select this project folder.
5. Pin **Prize Claw** and select its toolbar icon to open it.

## Publish on GitHub Pages

1. Create a GitHub repository and push this project to the `main` branch.
2. Open the repository's **Settings > Pages**.
3. Set the source to **GitHub Actions**.
4. Push a change or run the **Deploy Prize Claw to GitHub Pages** workflow manually.

GitHub will provide the live game URL after the workflow finishes.
